# A 프로토타입 개발 진입점

[서울 학부모 웹앱 열기](parent/index.html) · [실행 방법 및 구현 범위](parent/README.md)

별도 설치 없이 `parent/index.html`을 브라우저에서 엽니다. 서울 11개 관할의 2027 중입 배치조건 검토본을 반영한 가상 데이터 체험판입니다.

화면 흐름: 지도 옆 관할·출발점·신청유형·학급유형·특수학교 병행 조건 입력 → 관할별 후보와 경로 예시 → 별도 보호자 희망 → 담당 선생님 확인 요청.

관할별 근거리 행 수는 3·4·5로 분리하며 원문이 충돌하는 강동송파·성북강북·동작관악은 순위 산출을 보류합니다. 모든 규칙은 원문 대조값이며 교사 검수 전입니다. 실제 지도·학교·경로 API와 서버 제출이 연결되지 않아 공식 순위나 검증 완료를 표시하지 않습니다.

실제 데이터 연동에 앞서 [실행계획](../docs/development/실행계획_및_검증표.md)의 P0와 [서울 배치조건 확인 목록](../docs/review/2027중입_배치조건_검토본.html)을 확인해야 합니다. B OCR과 나이스 입력 지원은 구현 범위에서 제외합니다.
