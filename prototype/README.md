# A 프로토타입 개발 진입점

아직 구현 코드·실행 환경은 없습니다. 기술 스택은 지도·경로 조회 검증 후 결정합니다.

화면 흐름: 관할/연도/신청유형 → 주소·동 위치 확인 → 후보 지도와 비교표 → 근거리와 보호자 희망 구분 → 교사 검수·수정 → 작성 참고표.

비교표에는 정식 학교명, 특수학급 설치 상태와 적용연도, 이동방법, 거리·시간, 출처·조회시각, 검수 상태를 표시합니다. 보호자 탐색에서 학생 이름·장애 상세 입력을 요구하지 않습니다. 키보드 탐색과 지도 대신 읽을 수 있는 표를 제공합니다.

개발 시작 전 [실행계획](../docs/development/실행계획_및_검증표.md)의 P0 항목을 확인합니다. 경로 데이터를 확보하지 못하면 수동 지도 확인과 교사 검수로 연결하고 자동 산출 완료로 표시하지 않습니다. 모의 데모는 가상 데이터임을 명시합니다.

B OCR·입력 지원은 A 검증 후 별도 구현합니다. 현재 나이스 자동 등록이나 실제 학생 자료 업로드 기능은 범위에 포함되지 않습니다.
