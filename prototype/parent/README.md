# 서울 학부모용 중입배치 MAP

`index.html`을 브라우저로 열어 실행합니다. 설치·네트워크 연결 없이 사용 가능한 PC/모바일 웹 프로토타입입니다. 외부 근거 링크나 카카오맵을 열 때만 해당 연결이 필요합니다.

## 2026-09-20 서울 조건 반영

근거: [2027중입 배치조건 검토본](../../docs/review/2027중입_배치조건_검토본.html) §§1–6. 이 자료는 원문 추출·대조 결과이며 교사 검수 전입니다. 문서에 있는 확인 결과와 미확정 사항을 구분합니다.

### 지도 옆 선행 입력

- 2027학년도 / 서울 11개 관할 (수동 선택; 자동 관할 판정 미연동)
- 주민등록상 거주 출발점 (가상 주소 선택) / 아파트 동 (강동송파 아파트는 필수)
- 주민등록·실거주 요건 확인 또는 교사 상담 필요
- 기존 선정 / 신규 신청 / 학교급 변경 재선정 / 잘 모르겠음
- 일반학교 배치 희망 학급유형: 특수학급 또는 일반학급
- 특수학교 입학원서 제출 여부 / 제출 학교
- 특이배치 상담 필요 여부 (선택). 장애·피해 상세·증빙은 수집하지 않음

필수 입력 전에는 거리와 순위를 표시하지 않습니다. 조건 변경 시 이전 후보 계산과 보호자 희망을 초기화하며, 다시 적용하기 전까지 순위를 숨깁니다. 관할 변경 시 교사 선택도 초기화합니다.

### 관할별 행 구조

| 관할 | 근거리 행 수 | 보호자 희망 입력 예시 |
|---|---:|---|
| 동부·남부 | 3 | 별도 1개 |
| 북부 | 3 | 원문에 별도 행 없음; 보호자 의견은 상담 |
| 중부 | 3 | 3개 입력 예시; 문구 해석 확인 필요 |
| 강남서초 | 4 | 별도 1개 |
| 서부·강서양천·성동광진 | 5 | 별도 1개 |
| 강동송파·성북강북·동작관악 | 미확정 | 별도 1개; 근거리 순위는 표시하지 않음 |

알려진 행 수도 운영 확정값으로 취급하지 않습니다. 학교와 경로는 가상 데이터이며, 도보거리순 예시만 보여 줍니다. 일반학교는 학급유형을 통일합니다. 특수학교 입학원서 제출 분기는 알려진 행 수 안에서 특수학교 1순위 + 일반학교 N-1곳으로 시연합니다. 미확정 관할은 이 분기도 순위 산출을 보류합니다.

보호자 희망학교는 근거리 목록과 분리하며 근거리 학교와의 중복을 허용합니다. 보호자 희망의 필수 기재 여부를 임의로 정하지 않고 선택하지 않아도 교사에게 확인 요청할 수 있습니다.

### 거리 기준과 검수

카카오맵 / 2km 미만 도보, 이상 대중교통(자차 제외) / 서부만 대중교통 최단거리 / 강동송파만 1km 미만 m 일의 자리 표기를 안내합니다. 그 밖의 관할 표시 단위를 공식 규칙으로 주장하지 않습니다.

2km 판정에 먼저 사용할 거리, 도착점, 이동수단 변경 후 정렬, 다른 관할의 경로 선택은 미확정입니다. 이 기준을 추정해 공식 순위로 계산하지 않습니다. 도보·대중교통을 나란히 표시하고 환승 횟수·경로 미확인도 표현합니다. `routeMode`는 확인된 거리 임계값만 표현하는 정책 함수이며 실제 후보 정렬에는 적용하지 않습니다.

### 교사 확인 요청

후보·희망학교 검토 → 재학 학교별 가상 선생님 선택 → 확인 요청 → 제출 내용 확인 / 수정 요청. 요청 당시 조건·희망학교를 스냅샷으로 보존합니다. 취소하거나 수정 요청 상태일 때 편집할 수 있습니다. **규칙·경로가 미검증이므로 검증 완료 전환은 차단**했습니다. 공식 배치 신청이나 실제 학교 전달 기능은 아닙니다.

## 데이터 및 구현 한계

모든 학교·선생님·주소·거리는 가상 데이터입니다. 각 관할에 같은 시연 시나리오를 별도로 생성하며 실제 기관 확보 건수를 뜻하지 않습니다. 지도는 SVG 개념도이며 서울 실제 지도·학교 데이터·주소 검색·경로 API·서버·교사 권한 인증은 미연동입니다. 실제 주소나 개인정보를 넣는 자유 입력란은 제공하지 않습니다.

브라우저 저장 키는 `placement-parent-seoul-v2`입니다. 종전 v1의 고정 3개 희망 순위·검증 완료 데이터는 서울 규칙과 다르므로 불러오지 않습니다. 저장 제한 시 현재 화면에서만 사용할 수 있습니다. 다른 기기와 공유되지 않습니다.

## 파일 및 검증

- `index.html`, `style.css`: 지도와 선행 조건을 함께 보여 주는 반응형 화면
- `rules.js`: 출처가 연결된 관할별 원문 대조값, 조건 검사, 가상 후보 함수
- `app.js`: 조건 변경, 희망학교, 요청 상태, 브라우저 저장
- `tests/check.js`, `tests/run-tests.py`: 정책과 화면 상태 로직 회귀 검사

macOS에서 `python3 tests/run-tests.py`로 64개 검사를 실행합니다. JavaScriptCore와 최소 DOM 대역을 사용하므로 실제 브라우저 레이아웃·사용자 클릭 검증을 대신하지 않습니다.
