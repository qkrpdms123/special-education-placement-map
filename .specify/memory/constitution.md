# 중입배치 MAP Constitution

특수교육대상자의 중학교 진학을 위한 후보학교·통학정보 탐색 및 배치 신청자료 작성 지원 서비스.
이 문서는 기획·설계·구현·제출물 전반에 우선하는 최상위 규범이다.

## Core Principles

### I. 근거와 추정의 분리 (NON-NEGOTIABLE)

확인된 사실과 가정은 같은 문장에 섞지 않는다.

- 모든 규칙 행·데이터 행은 `source_document`, `source_locator`, `reviewed_by`, `verified_at` 네 필드를
  MUST 보유한다. 넷 중 하나라도 비면 그 행은 서비스에 반영하지 않는다.
- 검증 수준은 **실행 검증 / 명세 확인 / 인터뷰 진술 / 추정** 으로 구분해 MUST 표기한다.
  실행 검증이 아닌 것을 실행 검증으로 표기하지 않는다.
- 표본으로 확인한 것을 전수로 진술하지 않는다. "전국 확보 완료" 형태의 일반화는 MUST NOT 사용한다.

*근거*: 관할별 규칙이 실제로 달랐고(01 §3), 초기 가정 일부가 원문 확인으로 기각됐다. 출처가 없는 규칙은
교사가 검증할 수 없고, 검증할 수 없는 규칙은 이 서비스의 존재 이유를 무너뜨린다.

### II. 규칙 3-state와 unknown 비적용 (NON-NEGOTIABLE)

모든 관할 규칙은 **`confirmed`(확인됨) / `absent`(없음이 확인됨) / `unknown`(아직 모름)** 세 상태로 관리한다.

- `unknown`을 `absent`로 접지 않는다. 역도 같다.
- `unknown` 상태의 규칙은 자동 적용을 MUST NOT 한다. 화면에는 "관할 규칙 확인 중" 배지를 노출하고
  사람이 확인할 경로를 함께 제공한다.
- 한 관할에서 확인된 규칙을 다른 관할에 전이 적용하지 않는다.

*근거*: 형제·자매 특이배치 조항은 강남서초에서 확인됐고 동부·강동송파에서는 확인되지 않았다(06 §4).
없는 규칙을 안내하는 것과 있는 규칙을 빠뜨리는 것은 둘 다 실제 신청 오류를 만든다.

### III. AI는 초안, 확정은 사람

AI는 두 곳(서식→규칙 추출, 수기서류 항목 추출)에 사용하며, 두 경우 모두 산출물은 초안이다.

- 추출 결과는 **근거 문장(원문 인용)을 함께 저장**해야 MUST 하며, 교사가 원문과 대조할 수 있어야 한다.
- 교사 검수를 통과하지 않은 규칙은 서비스에 반영하지 않는다.
- 서명·직인은 추출·생성 대상이 아니며, OCR 결과가 보호자 동의를 대신하지 않는다.

*근거*: 규칙 해석에는 현장 판단이 필요하고, 책임 소재가 사람에게 남아야 한다(06 §2·§5).

### IV. 측정하지 않은 수치를 성과로 쓰지 않는다

- 시간 단축률·오류 감소율·설치율·과밀비율 등 수치는 **측정 또는 원문 검증 이전에 기획서·화면·발표자료에
  MUST NOT 기재**한다.
- 수치를 인용할 때는 기준일·분모·출처를 함께 적는다. 분모를 모르면 비율로 환산하지 않는다.
- 목표 수치와 측정 실적은 명시적으로 구분해 표기한다.

*근거*: 인계받은 설치율·과밀비율은 원문 연도·분모 검증 전이라 본문에서 제외했다(02 §1-2). 검증되지 않은
수치 하나가 문서 전체의 신뢰도를 깎는다.

### V. 범위 경계 준수

다음은 이 서비스가 수행하지 않는다. 화면·문서·발표 어디에서도 수행하는 것처럼 표현하지 않는다.

- 특수교육대상자 선정, 최종 배치 결정, 정원·과원 판정, 배치 가능성 예측
- 나이스 특수교육 배치시스템 자동 등록, 서명·직인 생성, OCR만으로 동의 완료 처리
- 근거리 후보를 "배치 확정 학교"로 표현하는 것
- 후보가 3곳 미만일 때 가짜 행을 채우거나 후보 범위를 임의 확장하는 것 → "교사 확인 필요"로 표시한다

*근거*: 최종 배치는 특수교육운영위원회의 심사 사항이다(01 §1). 경계를 넘는 표현은 보호자에게 잘못된
기대를 만들고 기관 도입을 막는다.

### VI. 결측의 보존

조회 실패·경로 없음·미확인은 값이 없는 상태 그대로 보존한다.

- 거리·소요시간을 `0m`/`0분`으로 대체하지 MUST NOT 한다. 직선거리를 제출용 통학거리로 치환하지 않는다.
- 거리는 숫자(`distance_m`)로 보관하고 표시 문자열과 분리한다. 표기 규칙은 관할 규칙이 정한다.
- 경로값에는 `route_provider`, `route_mode`, `queried_at`을 MUST 병기한다. 기준 지도와 값이 다를 수
  있다는 사실을 화면에 표기한다.
- 원본 조회값과 사람이 수정한 값은 분리 보관하고, 수정에는 사유를 남긴다.

*근거*: 서식이 기준으로 삼는 도보·대중교통 경로 조회가 공개 API로 막혀 있다(04 §5). 대체 수단을 쓰는 한
값의 출처를 숨기는 순간 교육지원청의 재점검에서 어긋난다.

### VII. 규칙 버전 불변 보관

관할 규칙은 `district_office × admission_year × application_type`를 기본 키로 버전 관리한다.

- 이전 `rule_version`은 삭제하지 MUST NOT 한다. 과거 신청 건의 판단 근거가 남아야 한다.
- 규칙 변경은 덮어쓰기가 아니라 새 버전 발행으로 처리하고, 변경 근거와 검수자를 기록한다.
- 학년도 현황(2026 확인)과 차년도 계획(2027 신설·증설 예정)은 별도 상태로 구분하며,
  계획을 확정으로 표기하지 않는다(`confirmed` / `planned` / `unknown`).

*근거*: 계획과 서식은 매 학년도 새로 발간된다(06 §6). 이 서비스의 실질 운영비는 구축이 아니라 갱신이다.

## 데이터·개인정보 제약

- **최소 수집**: 지도 탐색 단계에서 학생 성명·생년월일·장애등록 상세·보호자 연락처를 수집하지 않는다.
  서식 작성 단계에서만, 그 단계에 필요한 항목만 받는다.
- **동의 근거 분리**: 공식 서식의 동의를 본 서비스의 수집·처리 근거로 전용하지 않는다.
- **원본 보관과 격리**: 교육지원청 배포 원본(HWP/PDF/XLSX)은 출처 URL·게시일·파일 해시와 함께 보관하되,
  개인정보가 포함될 수 있는 파일은 공개 저장소에 커밋하지 않는다.
- **수집 적법성**: 공개 게시물 수집은 robots.txt·이용약관을 확인한 뒤 수행하며, 과도한 요청을 하지 않는다.
- **식별자 규율**: 학교는 공식 학교코드로 연결한다. 동명이교를 이름만으로 연결하지 않는다.

## 검수 워크플로와 품질 게이트

규칙 한 행이 서비스에 반영되기까지의 경로는 고정이다.

`원본 수집 → 해시·출처 기록 → 파싱 → AI 규칙 추출(근거 문장 병기) → 교사 검수 → rule_version 확정 → 반영`

- **게이트 1(출처)**: 네 개 출처 필드가 채워지지 않은 행은 다음 단계로 넘기지 않는다.
- **게이트 2(검수)**: 교사 검수 `review_status`가 승인이 아닌 행은 반영하지 않는다. `unknown`은 승인 대상이
  아니라 보류 대상이다.
- **게이트 3(사례 검증)**: 아래 경계 사례가 기대값과 일치해야 릴리스한다 — 1km 미만 m 단위 표기,
  2km 경계 전후, 동일 학교 중복 기재, 학급유형 혼재, 후보 3곳 미만, 경로 미조회, 차년도 신설 예정 학교,
  아파트 대표주소와 특정 동 불일치, 특수학교 병행 신청.
- **게이트 4(표현 점검)**: 배포 전 화면·문서에서 원칙 IV·V 위반 표현(미측정 수치, 배치 확정 표현)을 점검한다.

## Governance

- 이 헌법은 기획서·개발 명세·화면 문구·발표자료를 포함한 모든 산출물에 우선한다. 충돌 시 헌법이 이긴다.
- **개정 절차**: 개정안은 (1) 변경할 원칙, (2) 변경 근거가 되는 원문 또는 검증 결과, (3) 기존 산출물에 대한
  영향 범위를 함께 제시해야 한다. 근거 없는 개정은 하지 않는다.
- **버전 정책**: 시맨틱 버저닝을 따른다. MAJOR는 원칙의 제거·재정의, MINOR는 원칙·섹션 추가 또는 실질적
  확장, PATCH는 문구 정리·오타 수정.
- **준수 점검**: 모든 spec·plan·tasks 산출물은 Constitution Check를 통과해야 한다. 원칙에 어긋나는 설계는
  Complexity Tracking에 예외 사유와 대안 기각 이유를 적지 않는 한 진행하지 않는다.
- **표현 금지 목록**(원칙 I·IV·V의 운영 규칙): "전국 데이터 확보 완료", "특수교육 배치는 인원을 보지 않는다"
  (확인한 중입 관할의 신청서 작성 단계에 한정한다), "기존 특수교육 학교 지도는 없다", "공개자료가 곧 실시간 API",
  측정하지 않은 시간 단축률·오류 감소율.
