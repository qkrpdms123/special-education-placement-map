## ⚠️ 확인 필요 — 단정하지 않는다

| 항목 | 미확인 지점 | 영향 |
|---|---|---|
| 2km 판정 선행거리 | 도보거리 기준인지, 어느 경로인지 | 순위 산출 알고리즘 확정 불가 |
| 근거리 정렬 기준 | 이동수단 전환 후 재정렬 여부, 동거리 처리 | 동일 |
| 학교 도착점 | 정문 기준인지 | 거리값이 달라진다 |
| 형제 조항 관할별 존재 | 강남서초=확인, **동부·강동송파=미확인**, 그 외 미확인 | 3-state `unknown` 유지 |
| 인원 고려 여부 | 중입 서울 계열=미고려(교사 확인), **제주 고입=현원 명시**, 그 외 미확인 | 3-state `unknown` 유지 |
| 학교알리미 특수학급 항목 | OpenAPI 명세서(zip) 미확인 | 학교별 현황 자동화의 잔여 카드 |
| 동부 보호자 희망 행 필수 여부 | 원문에서 미확인 | 서식 검증 규칙 |
| 자동 수집 적법성 | 게시판 이용조건·robots.txt 미검토 | 운영 전 확인 필요 |

## ❌ 불가로 확인됨 — 대안을 함께 제시한다

| 항목 | 확인 결과 | 대안 |
|---|---|---|
| 학교별 특수학급 전국 API | 없음. 공공데이터는 시도 집계이며 기준일 2016 또는 PDF | 교육지원청 공표 문서·XLSX 수집 |
| 정원·잔여석 | 어떤 경로로도 비공개 | 중입 신청 단계에서는 **불필요**(범위 결정) |
| 카카오 도보 길찾기 API | 제휴 파트너 전용, 사전 계약 필요 | 제휴 문의 / 대체 API / 지도 딥링크 하이브리드 |
| 카카오 대중교통 길찾기 API | 공식 미개방 | 동일 |

## 🚫 범위 밖 — 하지 않는다고 명시한다

특수교육대상자 선정 · 최종 배치 결정 · 정원 판정 · 나이스 자동 등록 · 서명·직인 생성 · OCR만으로 동의 완료 처리.
근거리 후보를 ‘배치 확정 학교’로 표현하지 않는다.

## 남은 최대 리스크

**경로 API 하나다.** 서식이 요구하는 카카오맵 도보·대중교통 조회가 API로 막혀 있다. 리드타임이 가장 길어 제휴 문의를 먼저 보내야 한다.

지도 표시와 자동차 길찾기는 공개돼 있으므로, 최악의 경우에도 **직선거리 후보 추림 + 지도 딥링크 + 교사 검수** 형태로 서식 정합성 100%를 유지할 수 있다. 이 경우 자동화율은 낮아지지만 서비스가 성립하지 않는 것은 아니다.

## 기획서에 쓰지 않을 표현

- “전국 데이터 확보 완료” — 표본 조사다
- “특수교육 배치는 인원을 보지 않는다” — 중입·해당 관할·신청서 작성 단계에 한정
- “기존 특수교육 학교 지도는 없다” — 수원 사례가 있다
- “공개자료가 곧 실시간 API” — 문서 수집이다
- 측정하지 않은 시간 단축률·오류 감소율
