# 고입 확장 근거 및 지역 공개자료 확보 검증

확인일: 2026-09-13. 전국 전수조사가 아닌 서울·경기·인천·제주·경남의 공식 페이지 표본 조사다. 공개 계획·빈 서식 수집을 검증했으며 실제 학생 신청이나 자료 제출은 하지 않았다.

## 결론

1. 고입도 학교·학급 유형과 통학 등 여러 조건을 비교하고 서류를 준비하는 업무가 확인된다. 다만 중입보다 더 어렵다는 비교나 현재 불편의 비율·작업시간은 확인하지 못했다.
2. 서울 밖에서도 교육청·교육지원청이 계획·빈 서식·학교 현황 파일을 공개한다. 제주 HWPX 1건은 실제 다운로드와 본문 텍스트 추출까지 성공했다.
3. 모든 지역 자료를 자동으로 확보·정규화할 수 있다고 검증한 것은 아니다. 게시 위치·파일 형식·적용 학년도·신청유형이 다르다.
4. 첫 MVP는 중입을 유지하고 고입은 확장 가설로 제시한다. 주소만으로 고입 후보를 순위화하지 않는다.

## E5. 고등학교 선택의 복합성

박진수·정동영(2013), 「특수교육 대상 학생 부모의 자녀 고등학교 선택요인 분석」, 특수교육교과교육연구 6(2), 25–45. 공개 초록·서지정보 확인, 본문 미검토.

특수교육·학생 특성·통학 등 복수 요인이 고등학교 선택에 작용한다는 연구다. 고입도 정보 비교 지원을 검토할 근거가 된다. 오래된 선택요인 연구이므로 현재 행정 부담이나 우리 앱 수요를 직접 입증하는 자료로 쓰지 않는다.

- 실제 검증 대상: `2027학년도 특수교육대상자 고등학교 입학 전형 계획_최종.hwpx`.

- HTTP 다운로드 후 HWPX 압축 내부 `Contents/section*.xml`에서 본문 추출 성공. 미리보기 텍스트는 중간에 끊겨 본문 추출로 보완함. 표의 화면 배치와 인쇄 페이지는 검증하지 않음.

확인 내용: 2절은 대상학교를 특수학교·특수학급 설치교·미설치교로 구분한다. 서식2의 작성 안내는 가장 가까운 학교를 포함한 희망교 3곳 기재를 요구하며, 거리 외에도 통학여건·교육환경·학교 현원 등을 고려하고 희망과 다른 결과가 가능함을 안내한다. 따라서 서울 D·S의 ‘근거리 3개+보호자 희망’ 구조를 그대로 적용하면 안 된다.

제주과학고·제주외국어고에 대한 별도 전형 안내도 있어 학교 유형별 분기가 필요하다. 이 자료는 고입 신청 준비의 복합성을 보여주지만 신청자가 느끼는 어려움의 정도를 측정한 자료는 아니다.

## E8. 유사 서비스 발견: 수원 설치 현황 지도

[수원교육지원청 공고](https://goesw.kr/goesw/na/ntt/selectNttInfo.do?bbsId=11066&mi=18949&nttSn=560405)가 [수원 특수학급·특수학교 설치 현황 지도](https://school2026.github.io/map/)로 연결한다.

지도 페이지는 2026.9.1. 기준을 표시하며 주소·학교명 검색, 가까운 학교 항목과 카카오맵 자동차 길찾기 안내가 있다. 거리 표시는 직선거리 추정값이라고 안내한다. 이번에는 페이지 문구·컨트롤 존재만 확인했으며 주소 입력·지도 동작·데이터 정확성은 테스트하지 않았다. 정적 열람에 나타난 0교·0학급은 실제 집계로 사용하지 않는다.

이 발견으로 ‘기존 특수교육 학교 지도는 없다’는 주장은 사용할 수 없다. 차별성 후보는 관할·연도·유형별 규칙, 지침에 맞는 경로 확인, 신청서 행 구성·교사 검수다. 수원 서비스에 이러한 기능이 모두 없다고 확인한 것은 아니므로 기능 비교 테스트가 남아 있다.

## 데이터 확보의 현실적인 방법

1. 지역·담당기관·학교급별 원문 게시물 목록 작성. 같은 지역의 본청과 지원청 중복 게시를 추적한다.
2. 계획·빈 서식·학교 현황을 따로 수집하고 파일명·확보일·해시·적용연도·수정공고 여부 기록.
3. HWPX는 XML, XLSX는 행·열, PDF/HWP는 형식에 맞춰 추출. 이번에 실제 검증한 것은 HWPX 1건뿐이다.
4. 학교정보는 학교코드·정식명칭·설치상태·기준연도·출처로 정리. 주소·좌표는 별도 공식 데이터로 보강한다.
5. 규칙은 관할·학교급·신청유형·학년도와 함께 보존한다. ‘3희망’과 ‘근거리3+희망’을 같은 필드로 덮어쓰지 않는다.
6. 표 구조·조건문·예외를 담당 교사가 검수한 뒤 적용한다. 자동 추출 성공과 규칙 검증 완료는 구분한다.

공개 파일만으로 실제 지원자 기록·배치결과·실시간 정원·최종 적합성은 확보되지 않는다. 학생정보가 있는 현황 자료는 반입하지 않고 학교 단위 비개인정보인지 먼저 확인한다. 원문 재배포·자동 수집 이용조건도 실제 운영 전에 확인한다. 이번 GitHub에는 링크·검증 결과만 기록한다.

## 이번 공모전 문구

“서울 외 경기·인천·제주 등에서도 특수교육대상자 입학 계획과 신청서식, 학교 현황 자료의 공개를 확인했다. 제주 고입 계획 HWPX는 실제 다운로드와 본문 추출을 검증했다. 우선 한 관할의 중입 신청 준비를 구현하고, 지역별 자료를 정규화·검수하는 체계를 바탕으로 타 지역 및 고입으로 확장할 계획이다.”

고입의 확장은 가능성이 확인된 단계다. ‘전국 확보 완료’, ‘고입은 중입보다 더 어렵다’, ‘전국에 같은 거리순 3개 규칙 적용’, ‘공개자료가 곧 실시간 API’라는 표현은 사용하지 않는다.
