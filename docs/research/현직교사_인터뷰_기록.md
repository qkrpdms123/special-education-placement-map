# 현직 특수교사 심층 인터뷰 기록 — 1차 자료

> **작성 목적.** 국가통계가 답해주지 못하는 구간 — *배치 신청 준비에 실제로 얼마나 걸리는가, 어디에서 틀리는가* — 을 현직자 진술로 메운다.
> **문서 지위.** 이 문서는 **1차 자료(primary source)**다. 2차 인용이 아니라 대표자가 직접 수집했다.
> **표본.** 현직 특수교사 **1명**, 심층 인터뷰 **2회**. 이 문서의 어떤 수치도 전국 추정치가 아니다.

---

## 0. 이 문서를 읽는 규칙 — 먼저 읽을 것

기획서의 원칙은 「확인된 것과 가정을 구분한다」와 「측정하지 않은 수치를 성과로 쓰지 않는다」이다. 인터뷰는 그 사이에 있다. 측정은 맞지만 표본이 1명이다. 따라서 **쓰는 방식이 정해져 있다.**

| 구분 | 이 인터뷰로 말할 수 있는가 | 표현 |
|---|---|---|
| 업무가 **존재하는가** | ✅ 그렇다 | "현직 교사가 수행하는 업무다" |
| 업무의 **구조·순서** | ✅ 그렇다 | "다음 순서로 진행된다" |
| 어떤 **오류 유형**이 발생하는가 | ✅ 그렇다 | "다음 항목에서 수정이 발생했다" |
| 한 건에 **몇 분** 걸리는가 | ⚠️ 사례로만 | "이 교사의 경우 N분이었다" |
| 전국 교사가 **평균 몇 분** 쓰는가 | ❌ 아니다 | — (V3 설문의 몫) |
| **오류율이 몇 %**인가 | ❌ 아니다 | — (V3 설문의 몫) |

> 🔻 **"오류율"이라는 단어를 이 문서와 기획서 본문에서 쓰지 않는다.**
> 율은 분모가 필요하다. 표본 1명의 분모는 "그 교사가 그 해에 작성한 건수"이고, 그것은 **사례 빈도**이지 비율이 아니다.
> 대신 **「작성 건수 N건 중 수정이 발생한 건수 M건」**처럼 분모와 분자를 그대로 적는다. 평가위원은 이 정직함을 읽는다.

## 1. 인터뷰 개요

| 항목 | 1회차 | 2회차 |
|---|---|---|
| 일시 | `[ 2026-__-__ ]` | `[ 2026-__-__ ]` |
| 방식 | `[ 대면 / 통화 / 화상 ]` | `[ 대면 / 통화 / 화상 ]` |
| 소요 | `[ __분 ]` | `[ __분 ]` |
| 성격 | **탐색적** — 가장 비효율적인 업무 식별 | **구조화** — 시간·오류 실측 확인 |
| 기록 | `[ 메모 / 녹취 ]` | `[ 메모 / 녹취 ]` |

### 대상자 프로필

익명 처리한다. 기획서에는 직위·경력·담당 과정만 쓰고 소속 학교명과 이름은 쓰지 않는다.

| 항목 | 내용 |
|---|---|
| 직위 | 현직 특수교사 |
| 근무 형태 | `[ 초등학교 특수학급 / 중학교 특수학급 / 특수학교 ]` |
| 교직 경력 | `[ __년 ]` |
| 중입 배치 신청 업무 경험 | `[ __개 학년도 ]` |
| 관할 교육지원청 | `[ 관할명 — 기획서에는 코드로 표기 ]` |
| 인용 동의 | `[ ] 익명 인용 동의 확인 · `[ 확인일 ]` |

> **동의 없이 인용하지 않는다.** 익명이어도 마찬가지다. 2차 발표자료에 쓸 경우 범위를 다시 확인한다.

## 2. 1회차 — "가장 비효율적인 업무가 무엇입니까"

### 질문의 설계

막연히 "힘든 일"을 묻지 않았다. **"가장 비효율적인 업무"**로 한정해 물었다.
힘든 일은 아이를 가르치는 일에도 있다. 그건 기술로 해결할 수 없다.
**비효율은 반복과 수작업에서 나오고, 그것은 해결할 수 있는 종류의 문제다.**

### 답변

`[ 교사가 실제로 지목한 업무를 그대로 적는다. 요약하지 말고 표현을 살린다. ]`

### 업무의 구조 — 교사가 설명한 순서

| 단계 | 하는 일 | 도구 |
|---|---|---|
| 1 | `[ 예: 학생 거주지 확인 ]` | `[ ]` |
| 2 | `[ 예: 주변 중학교 검색 ]` | `[ ]` |
| 3 | `[ 예: 특수학급 설치 여부 확인 ]` | `[ ]` |
| 4 | `[ 예: 카카오맵으로 거리·소요시간 조회 ]` | `[ ]` |
| 5 | `[ 예: 근거리 순위 판정 ]` | `[ ]` |
| 6 | `[ 예: 서식 기재 ]` | `[ ]` |
| 7 | `[ 예: 보호자 수기 제출 자료를 업무시스템에 재입력 ]` | `[ ]` |
| 8 | `[ 예: 제출 전 검토 ]` | `[ ]` |

> **이 표가 기획서 §3-2 before/after의 'before' 열 근거가 된다.**
> 현재 본문의 before는 서식 원문에서 역산한 것이다. 인터뷰로 확인되면 **추정이 아니라 진술**이 된다.

### 1회차에서 확정하지 못한 것

`[ 2회차를 하기로 한 이유를 적는다. 예: 시간을 물었으나 "꽤 걸린다" 수준이었다 ]`

## 3. 2회차 — 시간과 오류를 숫자로 확인

> 2회차는 **되묻기 위한 자리**였다. 1회차의 진술을 서식 원문(D·S·G)과 대조한 뒤,
> **문서가 요구하는 항목을 하나씩 짚으며** 실제 소요와 수정 경험을 확인했다.

### 3-1. 작성 시간

기준 학년도: `[ 20__학년도 ]` · 해당 학년도 중입 배치 신청 담당 학생 수: **`[ __ ]`명**

| 구간 | 학생 1명당 소요 | 확인 방식 |
|---|---|---|
| 후보학교 탐색(특수학급 설치교 확인) | `[ __분 ]` | `[ 기억 / 기록 확인 ]` |
| 거리·소요시간 조회(지도 서비스) | `[ __분 ]` | `[ ]` |
| 근거리 순위 판정·검토 | `[ __분 ]` | `[ ]` |
| 서식 기재 | `[ __분 ]` | `[ ]` |
| 보호자 제출 자료 재입력 | `[ __분 ]` | `[ ]` |
| **학생 1명당 합계** | **`[ __분 ]`** | |
| **담당 학생 전체 합계** | **`[ __분 ≈ __시간 ]`** | `[ __명 × __분 ]` |

> **부담의 성격.** 이 시간은 **수업 중에는 낼 수 없는 시간**이다. 발생 시기도 특정되어 있다.
> 교사 진술: `[ 언제 하는가 — 예: 방과 후, 특정 시기에 집중 ]`
> `[ 동시에 진행 중인 다른 업무가 있었다면 적는다 ]`

### 3-2. 수정이 발생한 항목 — "율"이 아니라 "건"으로 적는다

| 수정이 발생한 항목 | 발생 여부 | 건수 | 발견 시점 | 후속 조치 |
|---|---|---|---|---|
| 학교명·학교 특정 오류 | `[ ]` | `[ ]` | `[ 자체검토 / 반려 ]` | `[ ]` |
| 통학거리 수치 | `[ ]` | `[ ]` | `[ ]` | `[ ]` |
| 소요시간 | `[ ]` | `[ ]` | `[ ]` | `[ ]` |
| 통학방법(2km 도보·대중교통 전환) | `[ ]` | `[ ]` | `[ ]` | `[ ]` |
| 학급유형 혼재 기재 | `[ ]` | `[ ]` | `[ ]` | `[ ]` |
| 근거리 순위 | `[ ]` | `[ ]` | `[ ]` | `[ ]` |
| 보호자 희망학교 행 누락 | `[ ]` | `[ ]` | `[ ]` | `[ ]` |
| 기타 `[ ]` | `[ ]` | `[ ]` | `[ ]` | `[ ]` |

**집계 — 분모와 분자를 함께 적는다**

- 작성한 신청 건수: **`[ __ ]`건**
- 그중 수정이 필요했던 건수: **`[ __ ]`건**
- 그중 **교육지원청 반려**로 확인된 건수: **`[ __ ]`건**
- 후속 조치: 나이스 수정 입력 `[ __ ]`건 / 수정공문 `[ __ ]`건
- 수정 1건당 추가 소요: `[ __분 ]`

> **표기 규칙.** 기획서에는 **"N건 중 M건"**으로 쓴다. `M/N × 100`을 계산해 적지 않는다.
> 서식 원문 D·S에 **"오류 발생 시 나이스 수정 입력 또는 수정공문"** 절차가 명시되어 있다 [D·S 서식1-2].
> **문서가 오류를 전제하고 절차를 마련해 두었다는 사실 자체**가, 인터뷰와 독립된 두 번째 근거다.

### 3-3. 서식 원문과 대조한 결과

| 교사 진술 | 서식 원문 | 일치 여부 |
|---|---|---|
| `[ ]` | `[ D/S/G 어느 문서 어느 항목 ]` | `[ ✅ 일치 / ⚠️ 차이 ]` |

> **차이가 나온 항목이 있다면 그것도 적는다.** 진술과 문서가 100% 일치하는 기록은 오히려 의심받는다.

## 4. 이 인터뷰로 확인된 것 / 확인되지 않은 것

### ✅ 확인된 것

1. `[ ]`
2. `[ ]`
3. `[ ]`

### ❌ 이 인터뷰로는 확인되지 않는 것 — V3 설문으로 넘긴다

| 남은 질문 | 이유 | 넘길 곳 |
|---|---|---|
| 다른 교사도 같은 시간을 쓰는가 | 표본 1명 | **V3 특수교사 설문** |
| 관할이 다르면 절차도 다른가 | 1개 관할 | **V1 + V3** |
| 보호자 쪽 소요시간·막히는 항목 | 교사 시점의 진술 | **V4 보호자 설문** |
| 교육지원청 담당자의 재확인 실무 시간 | 학교 시점의 진술 | **V5 담당자 인터뷰** |

> **인터뷰의 값은 V3 설문의 기준값(anchor)이 된다.** 설문 문항을 백지에서 만들지 않고,
> "이 교사는 학생 1명당 `[ __ ]`분이라고 답했다"를 **선택지 구간 설계의 출발점**으로 쓴다.
> 이것이 인터뷰를 먼저 한 실질적인 이득이다.

## 5. 기획서에 쓰는 방식

| 위치 | 쓰는 내용 |
|---|---|
| §1-1 (25점) | 인터뷰가 **아이디어의 출처**임을 밝힌다. 1회차 질문 설계 → 2회차 확인 → 원문 대조의 3단 구조 |
| §1-2 (15점) | "이 단계는 측정된 적이 없다" 뒤에 **"그래서 직접 확인했다"**를 붙인다 |
| §3-2 (10점) | before 열의 **근거**로 쓴다 |
| §4-1 (10점) | 진행 내역 표의 **첫 행**. 대표자가 직접 수행한 1차 조사 |

### 쓰지 않을 표현

- **"오류율 __%"** — 표본 1명이다
- **"특수교사는 평균 __분을 쓴다"** — 1명의 사례다
- **"현장 조사를 완료했다"** — 인터뷰 2회다
- 교사의 **소속 학교·실명** — 익명 인용만 한다
- 인터뷰 진술을 **따옴표 없이 사실 서술처럼** — 출처가 인터뷰임을 매번 밝힌다
