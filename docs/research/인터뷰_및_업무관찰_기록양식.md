# 인터뷰 및 업무관찰 기록 양식

이 파일은 빈 양식이다. 실제 개인정보·녹음·학생 신청서를 Git에 저장하지 않는다. 공유 가능한 익명 요약만 별도로 작성한다.

## 인터뷰 1건

- 기록 ID / 일자:
- 참여자 역할 / 중입배치 경험 시기 / 적용 관할:
- 모집 경로 / 면담자:
- 목적 설명 및 참여 의사 확인:
- 녹음 허용 / 익명 인용 허용 / 공유 범위:
- 최근 실제 경험의 시작과 종료:
- 사용한 문서·도구:
- 어려웠던 단계와 구체적 사건:
- 잘 해결된 단계 / 필요 없다고 한 기능:
- 영향: 추가 작업, 대기, 재문의 등:
- 시간·빈도: 실측 / 기록 확인 / 기억 기반 추정 중 구분:
- 익명 인용 및 맥락:
- 확인 가능한 근거 문서·위치:
- 인터뷰어 해석(발언과 분리):
- 반대 증거 / 새로 생긴 질문:
- 제품 결정에 미치는 영향:
- 추가 확인 담당 / 예정일:
