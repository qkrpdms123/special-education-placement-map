## 4. 렌더링 방법 (재현)

pdftoppm·python이 없는 Windows 기기에서 PDF를 쪽 단위 PNG로 만드는 방법. PowerShell 5.1에서 WinRT `Windows.Data.Pdf.PdfDocument`를 쓴다. 스크립트는 세션 스크래치패드 `render.ps1`에 있었으며 핵심은 다음과 같다.

```powershell
Add-Type -AssemblyName System.Runtime.WindowsRuntime
$null = [Windows.Data.Pdf.PdfDocument,Windows.Data.Pdf,ContentType=WindowsRuntime]
# StorageFile.GetFileFromPathAsync → PdfDocument.LoadFromFileAsync → 쪽마다 GetPage(i).RenderToStreamAsync(stream, opts)
# opts.DestinationWidth = 1600 (한 쪽) / 2600 (두 쪽 모아찍기). AsTask 로 await.
```

2쪽 모아찍기 PDF는 System.Drawing으로 좌우 반을 잘라 한 쪽씩 만들었다.
