## 여는 방법

**GitHub 웹에서는 렌더링되지 않는다.** GitHub는 저장소의 HTML을 화면으로 보여주지 않고 소스만 표시한다. 저장소가 private이라 GitHub Pages도 쓸 수 없다.

따라서 둘 중 하나로 연다.

- 저장소를 클론한 뒤 파일을 브라우저로 열기
- GitHub 파일 화면에서 **Download raw file** 로 내려받아 열기

각 파일은 단일 HTML이며 외부 요청은 구글 폰트뿐이다. 오프라인에서도 글꼴만 대체되고 내용은 모두 보인다.

## 기획안 검토본 읽는 법

점선 테두리에 노란 바탕인 블록은 **최종 제출 시 제거할 내부 메모**다. 상단 범례에 표시돼 있다. 각 절 왼쪽의 숫자는 공식 평가 배점(40/30/20/10)이다.
