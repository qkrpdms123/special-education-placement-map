3. 주요 결정 사항 및 맥락

결정 사항

  • 【표 10】은 11개 관할 전수 표로 교체한다(요약 압축형 아님)
  • 【표 28】의 "규칙이 관할마다 다르다"는 삭제가 아니라 '보류 → 해제'로 서술한다 — §4-1 주도성 서사가 강해진다
  • V1은 완료 처리하고 새 V1'을 타 시도 확장으로 둔다
  • 분량 초과분은 §2-2에서 줄인다(배점 10점 대비 가장 두꺼움). §3-1·3-2는 절대 줄이지 않는다
  • 원본 HWP/PDF는 저장소에 커밋하지 않는다. 수집 스크립트는 커밋한다
  • 저장소는 현재 PUBLIC. 사용자가 "지금 바로 푸시" 결정

맥락 — 이번에 확인된 핵심 사실

  • 근거리 학교 기재 수가 관할마다 3·4·5개로 갈린다. 3 = 동부·남부·북부·중부 / 4 = 강남서초 / 5 = 서부·강서양천·성동광진
  • 북부 서식에는 보호자 희망 행이 아예 없다. 중부만 희망교를 1·2·3순위로 받는다
  • 거리 기준은 11/11 동일 — 카카오맵, 2km 미만 도보 / 2km 이상 대중교통(자차 제외)
  • 서부 신·구 대조표에 카카오맵 지정 사유가 있다 — "대중교통 거리(km) 산출 기능이 있는 포털사이트 명시 — 네이버 지도: X, 카카오맵: O". 경로 조회 공급자 선택의 행정적 근거
  • 관할 기준은 단계마다 다르다. 거리 산정 = 주민등록상 거주지 / 심사·배치 = 희망 학교 관할(이관받은 곳)
  • 강동송파만 출발지를 아파트 동까지, 1km 미만을 m 일의 자리로 요구
  • 중부만 특이배치 가족관계증명서가 1개월(공통 조항은 3개월) — 같은 문서 안에서 어긋남
