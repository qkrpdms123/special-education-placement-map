# 수상자 발표 분석과 중입배치 MAP 인터뷰·기획 보완계획

작성일: 2026-09-13

## 1. 먼저 내릴 판단

중입배치 MAP에 지금 가장 필요한 것은 **실제 사례에서 어떤 작업이 오래 걸리고, 왜 다시 해야 하며, 어떤 결과면 믿고 사용할 수 있는지 보여주는 근거**다. A(주소 기반 후보학교·통학정보·신청자료 검수)를 1순위로 유지한다. B(OCR→나이스 입력 지원)는 실제 재입력량과 항목 대응을 확인한 뒤 확장한다.

현재 갖고 있는 강점은 현직 특수교사에게서 출발한 문제, 업로드된 업무·서식 분석 3개, 관할별 차이와 미확정 규칙 목록이다. 부족한 것은 학부모 직접 인터뷰, 교사 업무 관찰·시간 측정, 접수기관의 오류·수정 근거, 실제 경로 결과의 재현 가능성이다.

이번 자료는 사용자 제공 발표 전사문이다. 질의응답형 인터뷰 녹취라기보다 수상팀의 서비스·성과 발표에 가깝다. 인명·서비스명·숫자에 전사 오류 가능성이 있어 임의 복원하지 않는다. 아래 시각은 제공 전사문의 타임스탬프이며 외부 검증된 인용이 아니다. 원본은 [발표 전사문](../research/수상자_발표_전사문.txt)에 보존했다.

전사문 24:02~24:08의 ‘14일→1일, 약 96%’는 숫자 그대로 계산하면 약 92.9%다. 전사·발표·측정단위 중 무엇이 다른지 알 수 없으므로 오류 원인을 단정하지 않는다. 우리 자료에서는 측정 단위, 시작·종료점, 계산식을 함께 남겨야 한다. 수상 사실만으로 발표의 모든 성과 수치가 검증되는 것은 아니다.

## 3. 우선 확보할 인터뷰와 산출물

아래 인원은 빠른 탐색을 위한 제안이며 통계적 대표성을 보장하는 기준이 아니다. 실제 섭외 가능성과 새로 발견되는 문제에 따라 조정한다.

| 우선 | 대상·제안 규모 | 알아낼 내용 | 남길 자료 |
|---|---|---|---|
| P0 | 최근 중입배치 경험 특수교사 3~5명, 그중 2~3명 업무 재현 | 단계별 시간, 반복 원인, 오류, 판단 규칙 | 업무 흐름표·시간 기록·익명 사례 |
| P0 | 중학교 진학을 준비 중이거나 최근 마친 보호자 4~6명 | 정보 찾기·이해·상담의 실제 어려움 | 최근 경험 여정·사용 자료·미해결 질문 |
| P0 | 해당 교육지원청/지원센터 담당자 1~2명 | 접수 검토, 수정 요청, 거리·순위 해석 | 규칙 답변표·비식별 수정 유형·검토 조건 |
| P1 | 개발자 1명과 경로 조회 실험 | 기준 지도와 같은 결과를 얻을 수 있는가 | 경로 비교·미지원 조건·비용 메모 |
| P1 | 기관 도입·운영 담당자 1~2명, 앞선 담당자와 겹칠 수 있음 | 실제 사용자·승인자·예산 담당·갱신 책임 | 도입 조건표·의사결정 경로 |

첫 관할을 중심으로 조사하고, 타 관할 사례는 차이 확인용으로 구분한다. 보호자는 교사 지인에게만 추천받지 말고 가능한 범위에서 디지털 사용이 익숙하지 않은 사람, 정보 탐색에 큰 어려움이 없었던 사람도 포함한다. 참여 거절이나 부정적 의견도 기록한다.

학교·학생 실명, 실제 집주소, 장애 진단·사건 상세는 인터뷰 목적에 필요한지 먼저 따진다. 사례 재현은 가상 주소와 빈 서식으로 진행한다. 녹음·발표 인용·공유 여부는 참여자에게 각각 설명하고 허용 범위를 기록한다. 실제 신청서 원본은 Git에 넣지 않는다.

## 4. 교사 인터뷰: ‘힘든가요?’에서 실제 작업으로

권장 방식: 30~45분 대화와 별도의 업무 재현. 처음에는 MAP을 보여주지 않고 최근 경험부터 듣는다.

1. 가장 최근 중입배치 준비를 한 번 떠올려 주세요. 처음 받은 자료와 최종 넘긴 자료는 무엇이었나요?
2. 주소 확인부터 학교·거리·시간 기재와 검수까지 어떤 순서로 했나요? 사용한 문서와 도구는 무엇인가요?
3. 가장 오래 걸린 단계는 무엇이었나요? 기억으로 말한 시간인지 실제 기록인지 구분해 주세요.
4. 다시 검색하거나 고쳐 쓴 사례가 있었나요? 무엇이 계기가 됐고 누가 수정을 요청했나요?
5. 학교 설치정보와 해당 학년도 변경사항은 어디서 확인했나요? 목록과 현장이 다른 적이 있었나요?
6. 2km 판정의 선행 거리, 경로 선택, 도착점, 동거리 순서는 어떻게 정했나요? 문서 근거와 관행을 나눠 주세요.
7. 근거리 3개와 보호자 희망이 같거나 후보가 부족하면 어떻게 처리했나요?
8. 자동 비교표를 받는다면 어떤 항목을 다시 확인해야 믿고 사용할 수 있나요?
9. 지금 방식으로도 충분히 잘 되는 단계는 무엇인가요? 도구가 추가되면 오히려 번거로운 단계가 있나요?
10. A의 학교 탐색·작성과 B의 수기 재입력을 각각 얼마나 자주, 얼마나 오래 하나요? 같은 학생의 전체 작업을 기준으로 비교해 주세요.

관찰 시 주소 확인, 설치학교 확인, 경로 검색, 기록, 규칙 검수, 수정 작업별 시작·종료를 기록한다. 전화 회신 등 대기시간과 실제 작업시간을 분리한다. 느린 원인이 경로 검색인지, 학교정보 갱신인지, 규칙 문의인지 분리해야 기능 우선순위를 정할 수 있다.

## 5. 보호자 인터뷰: 독립적인 사용자 가치 확인

권장 방식: 20~30분 최근 경험 대화, 이후 짧은 가상 탐색 과제.

1. 중학교 진학 준비를 시작할 때 가장 먼저 알고 싶었던 것은 무엇인가요?
2. 어떤 학교를 알아보았고, 그 정보를 어디에서 찾았나요? 처음부터 끝까지 순서대로 설명해 주세요.
3. 특수학급 설치 여부나 통학정보를 찾지 못해 다른 사람에게 물어본 적이 있나요? 어떤 질문이었나요?
4. 정보가 서로 다르거나 오래됐다고 느낀 경험이 있나요? 무엇을 믿고 판단했나요?
5. 학교 위치·통학 외에 꼭 확인해야 했던 정보는 무엇인가요? 지도만으로 해결하기 어려운 것은 무엇인가요?
6. 근거리 학교와 보호자 희망학교를 어떻게 이해했나요? 실제로 헷갈렸던 표현이 있었나요?
7. 준비 과정이 지연되거나 반복되면서 생긴 구체적인 영향이 있었나요? 없었다면 어떤 지원이 도움이 됐나요?
8. 교사의 설명만으로 충분했나요, 직접 비교할 필요가 있었나요? 직접 사용한다면 어느 시점인가요?

그 뒤 가상 비교표를 보여주고 ‘특수학급 설치가 확정된 학교’, ‘보호자 희망’, ‘교사 확인이 필요한 정보’를 찾아 설명하게 한다. ‘이 학교에 반드시 배치된다는 뜻인가요?’를 확인해 오해를 측정한다. 지도 읽기보다 표를 선호하는지, 휴대폰에서 과제를 마칠 수 있는지도 본다.

‘이런 앱이 있으면 좋겠죠?’의 찬성 수보다 실제 과제 완료, 막힌 지점, 반복 질문을 근거로 쓴다. 직접 사용 필요가 낮게 나오면 교사 중심 A와 보호자용 결과 공유 흐름을 우선할 수 있다.

## 6. 교육지원청 인터뷰: 규칙과 재작업 근거 확보

1. 접수된 자료에서 실제로 확인하는 항목은 무엇이고, 어떤 경우 학교에 수정 요청하나요?
2. 최근 중입배치에서 거리·학교명·학급유형·누락 관련 사례가 있었나요? 익명 유형이나 빈 서식으로 설명 가능한가요?
3. 빈도 기록이 있나요? 없다면 흔하다는 인상과 집계 수치를 구분할 수 있을까요?
4. 2km 기준거리, 순위 정렬, 출도착점, 경로 선택, 후보 범위와 동거리 처리의 근거 문서는 무엇인가요?
5. 학교 신설·증설의 확정 여부는 누가 언제 공지하나요? 잘못 표시된 정보를 정정하는 담당은 누구인가요?
6. 외부 도구의 결과표가 작성 참고자료로 유용하려면 어떤 출처·조건·확인 표시가 필요하나요?
7. 자동으로 처리하면 안 되는 예외와 반드시 담당자에게 연결할 상황은 무엇인가요?
8. 가상 사례 비교 검토가 가능하다면 누가 어떤 결과를 검토할 수 있나요?

담당자 구두 의견은 기관 공식 승인과 구분한다. 답변 일자·역할·적용 관할·연도·근거 위치를 남기고, 불명확한 답변은 규칙 상태를 unresolved로 유지한다.

## 7. 기획에서 보완할 다섯 가지

### ① 문제의 크기를 업무 단위로 표현

전국 특수교육대상자 수는 중입배치 이용자 수와 같지 않다. 첫 관할의 연간 해당 신청 건수, 교사 1인 담당 건수, 사례당 작업시간, 오류 수정 빈도를 확보한다. 연간 시간 추정은 `해당 신청 건수 × 사례당 평균시간`으로 하고, 표본·범위·추정임을 표시한다. 실제 예산 절감은 인건비 환산만으로 확정하지 않는다.

### ② 문제–기능–증거를 한 줄로 연결

| 가설 | 확인할 근거 | 기능 | 지표 |
|---|---|---|---|
| 설치학교와 통학정보를 찾는 데 반복 탐색이 필요 | 교사 관찰·보호자 최근 경험 | 연도별 학교정보와 경로 비교 | 탐색시간·미완료 과제 |
| 지역 작성 규칙 때문에 확인·수정이 반복 | 실제 서식·담당자 수정 사례 | 유형별 행 구성·중복·누락 검사 | 수정·누락 건수 |
| 결과를 믿기 위해 재조회해야 함 | 교사 검수 행동·기관 요구 | 출처·조회 조건·검수 이력 | 검수 포함 총시간·불일치 |
| 수기 재입력이 별도 부담 | 실제 입력 화면·교사 단계별 시간 | B 항목 추출·원본 대조 | 필드 정확도·검수 포함 입력시간 |

### ③ 도입 주체와 지불 주체 분리

보호자·교사가 사용자라는 사실만으로 기관 구매가 성립하지 않는다. 사용자, 검토·승인 담당자, 예산 담당자, 학교정보 갱신 담당을 각각 확인한다. 도입 문의에서는 ‘구매할 의향이 있나요?’보다 현재 대체수단, 도입 조건, 비용 부담, 연간 사용 시기, 운영 담당, 다음 검토 절차를 묻는다. 공문·실증 협의·구매 의향은 실제로 확보한 수준만 표현한다.

### ④ 기술이 아닌 결과의 신뢰성을 검증

카카오맵 화면과 같은 경로 결과를 확보할 수 있는지 별도 실험한다. 주소·아파트 동·학교 도착점·출발시각·경로 선택을 통제하고 교사 기준과 비교한다. 기능이 동작해도 미확정 규칙을 적용한 순위는 검증 완료가 아니다. 실패·미지원 상태와 수동 검수 경로도 데모에 포함한다.

### ⑤ ‘무엇이 나오면 방향을 바꿀지’ 미리 정하기

- 교사 검수를 포함하면 시간이 줄지 않는다 → 화면보다 조회 근거·검수 흐름을 먼저 개선.
- 보호자는 직접 탐색보다 교사의 비교 설명을 원한다 → 보호자 독립 앱보다 결과 공유·설명 기능 우선.
- 핵심 병목이 경로 검색보다 학교 현황 불확실성이다 → 연도별 데이터 갱신·확인 흐름 우선.
- 공식 기준과 같은 경로를 얻을 수 없다 → 자동 산출 범위를 줄이고 수동 확인 지원으로 검증.
- B가 특정 서식에서만 효과가 있다 → 그 서식으로 제한하고 전면 자동입력 주장 보류.

이 기준은 실패 선언이 아니라 인터뷰가 실제 제품 결정에 영향을 주도록 하는 장치다.

## 8. 최소 검증 묶음 제안

1. **문제 증거:** 교사·보호자·기관 인터뷰 기록과 익명 인용, 반대 사례 포함.
2. **업무 증거:** 교사의 가상 사례 재현 3~5건부터 단계별 시간 측정. 일반·경계·실패 사례로 확장.
3. **규칙 증거:** 근거 문서–규칙–미확정 질문–교사/담당자 답변 대응표.
4. **기술 증거:** 같은 조건의 기준 지도와 A 결과 비교, 실패 사례 포함.
5. **효과 증거:** 교사 검수 포함 기존/MVP 총시간, 수정·누락 건수, 순위·거리 일치.
6. **실행 증거:** 팀별 책임·산출물·검토일, 기관 검토 가능 범위와 다음 단계.

같은 사례를 먼저 수행해 생기는 학습 효과를 줄이기 위해 기존/MVP 순서를 번갈아 적용하거나 유사 난이도 과제를 교차 배정한다. 기록에는 원자료 시간, 사례 수, 평균·중앙값·범위, 제외한 사례와 이유를 남긴다. 적은 탐색 표본으로 전체 교사·학부모의 효과를 일반화하지 않는다.

인터뷰 메모와 시간 기록은 [기록 양식](../research/인터뷰_및_업무관찰_기록양식.md)을 사용한다. 학생 개인정보가 없는 요약본만 저장소에 반영한다.

## 9. 다음 활동 순서

첫째, 특수교사 친구와 가상 사례 한 건을 함께 재현하고 단계별 시간과 미확정 규칙을 적는다. 둘째, 이때 발견한 질문으로 다른 교사와 보호자를 인터뷰한다. 셋째, 교육지원청에 규칙·수정 유형을 확인한다. 넷째, 확인된 병목으로 A 화면과 기술 실험을 조정한다. 다섯째, 결과를 제안서의 문제·해결·검증·팀 실행 항목에 연결한다.

기획서의 핵심 문장은 측정 후 다음 구조로 완성한다: ‘[관할·대상]의 [참여자 수]명과 [사례 수]건을 확인한 결과 [구체 단계]에서 [관찰한 병목]이 나타났다. A는 [기능]으로 이를 지원하며, [같은 조건]에서 [검수 포함 지표]로 효과를 검증했다.’ 빈칸은 실제 기록으로만 채운다.
