【그림 3】 배치 신청 행정의 AS-IS / TO-BE
특수교육대상자 중학교 입학 배치 신청 — 6단계 처리 흐름
현재AS-IS
① 안내
교육지원청이 계획 HWP 게시 → 학교 전달 → 보호자가 읽고 해석
② 보호자 작성
지도 검색을 반복하며 학교·거리·시간을 수기 기재
③ 교사 확인
학생마다 지도 재조회, 행 수·중복·단위 수동 대조
④ 등록·첨부
수기 내용을 업무시스템에 재입력
⑤ 교육지원청 검토
거리 재점검 → 오류 시 수정 요청·수정공문
⑥ 심사
특수교육운영위원회 심사
▼▼▼▼▼
도입 후TO-BE
① 안내
관할·학년도를 자동 판정하여 해당 규칙만 제시
② 보호자 작성
주소 입력 → 후보·거리·소요시간 비교표 자동 산출
③ 교사 확인
중복·누락·학급유형 혼재 자동 점검, 수정 사유 기록
④ 등록·첨부
항목 추출·검수 후 입력 지원 (B 트랙)
⑤ 교육지원청 검토
각 값에 출처·조회조건·수정이력 첨부 → 재확인 대상 축소
⑥ 심사
변경 없음
서비스 범위 밖
혁신의 지점은 ⑤입니다. 현재 행정은 사후 점검으로 오류를 잡습니다. 신청 단계에서 관할 기준이 적용되면 오류 자체가 줄고, 각 값에 근거가 붙어 재확인 비용이 낮아집니다.
⑥ 특수교육대상자 선정과 최종 배치 결정은 교육지원청 특수교육운영위원회의 고유 권한이며 서비스 범위 밖입니다.
