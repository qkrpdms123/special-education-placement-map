  1. 한글로 옮기기 — 아래 흰 지면 안쪽을 마우스로 긁어 복사(Ctrl+C)한 뒤, 공고 첨부 양식 04_[아이디어_기획서]…hwp에 붙여넣기(Ctrl+V)합니다. 표와 그림이 그대로 따라갑니다.
  2. 분량 확인 — Ctrl+P → 대상을 'PDF로 저장', 용지 A4, 여백 '기본', 배율 100%, '배경 그래픽' 체크. 미리보기에 나오는 쪽수가 실제 분량입니다.
  3. 붙여넣은 뒤 한글에서 확인할 것 — 글꼴이 함초롬바탕 10pt인지, 줄간격 160%인지, 표가 본문 폭에 맞는지.
